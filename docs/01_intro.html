1.2.2 Functions

A function takes one or more objects as input, performs a task, and returns an output. We have already used several, such as sample(), length() and data.frame(). We can also write our own:

ls()
[1] "n"
# Define the function "square()"
square <- function(x) { return(x^2) }

# Run function on object, store as "result"
result <- square(n)

# Print the result in the console
print(result)
[1] 10000
ls()
[1] "n"      "result" "square"

AirPassengers is a dataset that comes built into R: the monthly totals of international airline passengers, in thousands, from January 1949 to December 1960. Stores information in three vectors:

# Three vectors with one value per month
passengers <- as.numeric(AirPassengers)
year       <- as.numeric(floor(time(AirPassengers)))
month      <- as.numeric(cycle(AirPassengers))

length(passengers)     # 144
[1] 144
# Access elements of a vector
passengers[1]          # first element: 112
[1] 112
passengers[1:3]        # elements 1 to 3: 112 118 132
[1] 112 118 132
passengers[c(1, 144)]  # first and last: 112 432
[1] 112 432

1.2.4 Dataframes

A dataframe is a two-dimensional object that stores data as a table, with rows and columns:

  • Each row is one observation (an individual, a month, a country, …).
  • Each column is one variable (income, education, number of passengers, …).

Every column of a dataframe is a vector, and all columns have the same length. So if we have several vectors of the same length, where position 1 in each vector refers to the same observation, position 2 to the next one, and so on, we can put them side by side as the columns of a dataframe with data.frame(). The three vectors year, month and passengers each have 144 elements, one per month, so together they form a dataframe with 144 rows and 3 columns:

# Create a dataset from the three vectors
df_air <- data.frame(year, month, passengers)
dim(df_air)            # 144 rows, 3 columns
[1] 144   3
head(df_air)

4 1949     4        129
5 1949     5        121

1.3 R Packages

A package is a collection of functions, data and documentation written by other R users, which extends what R can do. R comes with a basic set of functions (such as mean() or data.frame()), and packages add new ones for specific tasks. For example, dplyr adds functions to manipulate dataframes and ggplot2 adds functions to draw graphs. Thousands of packages are freely available on CRAN, the official R package repository.

Using a package takes two steps. First, install it, which downloads it to your computer. This is done only once per computer:

# Install once (downloads from CRAN)
install.packages("dplyr")

Second, load it with library(), which makes its functions available in your current R session. This has to be done every time you start R, so the library() lines usually go at the top of the script:

# Load every time you start R
library(dplyr)
